# FateGrid｜研究知識總綱 v0.1
更新：2026-09-23。用途：保存研究脈絡、明示推演規則的來源與可信度；不作醫療診斷或對真實個人未來的事實性預測。

## 1. 範圍與邊界
- 目標：以八字、十神、五行、大運、流年、地氣／居住環境、三元玄空為**可配置的文化敘事模型**，生成差異化人物、場景與事件。
- 研究／故事生成分離。排盤可核對曆法；五行權重、外形與命運的對應屬研究假設，不宣稱有實證預測效力。
- 主幹：本命 → 大運 → 流年 → 流月／流日／流時 → 環境／屋宅 → 事件。三元玄空優先作空間模型，三合為輔；遇不同流派不可暗中混用。
- 核心知識屬專案資產。公開倉庫不放個案出生全資料、家人資訊、地址、住家圖、病房資料、老師手稿原件、任何 API Key；樣本使用去識別與授權程序。

## 2. 資料層
- Person: person_id, birth_local, timezone, birthplace_precision, sex_for_traditional_rule(optional), source, consent, quality。
- NatalChart: 年月日時柱、日主、節氣邊界、真太陽時策略、曆法版本、計算來源、候選盤。
- TimeLayer: 大運、流年、流月、流日、流時；每層的干支／十神／權重／有效區間。
- Place: 地區與地物的抽象環境特徵、九宮、屋宅坐向、元運、流年／月飛星、資料精度。
- Observation: 觀測日期、可核查事實、資料來源、與推演分開儲存；不可事後回填成「預測命中」。
- Narrative: 角色、觸發條件、場景、事件模板、隨機種子與生成版本。

## 3. 規則分類與來源
**R0 可驗算：** 公曆／農曆轉換、節氣時間、干支排盤、藏干表、十神映射、五合六合沖刑害等「關係檢出」。需提供採用的曆法、門派表與來源。
**R1 研究假設：** 旺衰、祿／羊刃、傷官傷盡、傷官配印、七殺、拱／合化判準及五行剩餘力量。先列規則，再允許修改權重，不冒稱定論。
**R2 場景設定：** 地氣、產業與環境映射、玄空吉凶含義、人生事件／職業與外貌模型、世界觀、前世等；只作敘事設定，不推定現實個人特質。
**R3 禁止直接推定：** 病症、死亡時間、智力、道德、犯罪、個人能力、個案「命中」。涉及健康只能使用獨立、可信的醫學資訊和明確限制。

## 4. 研究中的具體問題
1. 子午沖作用強度：曾討論沖採 0.4，刑採 0.1，亦曾提及沖 0.5；都**只是待校準候選值**，不得硬編碼為普遍真理。
2. 申子半合是否成化，必先處理子水經沖後的剩餘量及月令、通根、透干等判準；「檢出合」不等於「成化」。
3. 拱／合化、祿／刃、傷官傷盡、奇格存活條件、物極必反，均需明列衝突規則和反例。
4. 分辨天干透出與地支本氣／餘氣、原局與運歲新進力量；同一因素在不同層不可無故重複加權。
5. 玄空先核定坐向與元運、順逆飛、流年／流月；不得以固定子山午向代表所有屋宅。
6. 外觀、臟象、性格／職業映射僅作可檢驗的故事假設，必須允許「未知／不推定」。

## 5. 樣本驗證
- 建立匿名個案 ID；事前鎖定規則版本、候選權重與輸出，事後記錄結果；區分探索集與保留驗證集。
- 每個案例記錄可用日期精度；缺時辰不可補造時柱。住所及環境變更須附有效日期。
- 驗證報告同時呈現錯誤、反例、信心不足與未觀測結果。不得只展示相符案例。
- 所有規則保存 source, version, status (confirmed convention / hypothesis / deprecated), conflicts, tests。
